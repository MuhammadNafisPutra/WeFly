# We Fly

Website satu halaman untuk agen perjalanan udara fiktif **We Fly**: pencarian penerbangan,
formulir pemesanan tiket, kartu destinasi promo (Bandung, Lombok, Bali), dan formulir kritik & saran.
Navigasi menandai bagian yang sedang dibaca secara otomatis saat halaman digulir.

Proyek UAS Pemrograman Web, Teknologi Informasi Universitas Lambung Mangkurat (2025).

## Teknologi
HTML5 · CSS3 (tanpa framework) · JavaScript

## Menjalankan
Buka `index.html` di browser.
